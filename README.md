# Oração Acessível\n\nProtótipo acadêmico do Projeto Integrador I, Curso Técnico em Tradução e Interpretação de Libras — IFTO, 2026.\n\nDiscentes: Eduarda Ferreira Santana Bispo e Leila Régia de Paiva Freitas.\n\nEsta aplicação demonstra oração ilustrada, texto em português e integração com VLibras. O VLibras produz tradução automática e não substitui trabalho humano de tradução, revisão ou interpretação em língua de sinais.\n\nAs 11 ilustrações são carregadas do repositório de origem de titularidade da autora; a versão acadêmica requer internet para carregá-las e para o VLibras. Não representa aprovação institucional do IFTO.\n\n## Deploy\nGitHub Actions envia ao diretório Locaweb `./public_html/oracaoacessivel/` com segredos HOST, USER, PASS.\n
